Frequently Asked Questions

Do my files leave my device?expand_more

The live tool experience is built around browser-side workflows, so selected files stay in your local browser session during processing.

Why do I choose a tool before uploading?expand_more

Each workflow has different file and input requirements. The launchpad helps users select the right tool first, then move into the correct upload or input step.

Can I use Convertly on mobile?expand_more

Yes. The interface is responsive and designed to work across desktop and mobile browsers.

Which kinds of tasks are supported right now?expand_more

The current launch-ready set includes PDF conversion, PDF compression and merging, OCR scanning, JPG to PNG conversion, QR generation, and JSON formatting.
